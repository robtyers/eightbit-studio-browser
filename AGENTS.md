# Eightbit Studio browser source

Follow docs/browser-edition.md and ADRs 0052/0053. Preserve the reduced browser workspace and existing shared workbench. Retain GPL, Apache and third-party notices. Never add firmware, private user projects, credentials or desktop hosts. Keep dependencies pinned and test changes at their owning layer. Publish a new tagged source release before deploying matching runtime changes; publishing requires explicit authorisation.
