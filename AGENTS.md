# Eightbit Studio browser source

Follow docs/browser-edition.md and ADRs 0052/0053/0055/0056/0057/0058/0059/0062/0063. Preserve the reduced browser workspace and existing shared workbench. Retain GPL, Apache and third-party notices. Only verified original Dragon 32/64, Spectrum 48K/128K/original +2 and source-bound original C64 and Vectrex development firmware is permitted. Development firmware status does not establish compatibility. Never add third-party firmware, private user projects, credentials or desktop hosts. Keep dependencies pinned and test changes at their owning layer. Publish a new tagged source release before deploying matching runtime changes; publishing requires explicit authorisation.
