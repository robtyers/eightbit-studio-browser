BBC Model B: getting started

Create, build and export

Choose BBC Micro Model B (32 KB) and BBC BASIC II in New Project. The schema-1 bbc.toml manifest names one source below src/. Creation and opening are inert. Save, then Build to produce a deterministic 80-track single-sided DFS SSD with PROGRAM and !BOOT. Export SSD creates a new file and refuses overwrite. A failed build never launches earlier output.

Your first programme

10 MODE 7
20 PRINT "HELLO FROM EIGHTBIT STUDIO 6502"
30 FOR N%=1 TO 5
40 PRINT N%
50 NEXT N%
60 END

Expected observation: a greeting and the numbers 1 to 5, followed by the BASIC prompt. Encoding tests do not establish this runtime observation.

Run controls

Configure MAME 0.289 and the matching BBC firmware folder. Run builds fresh output and requests the disc's !BOOT script through the BBC keyboard. Stop terminates Studio's owned process; Restart builds and starts again. Keyboard and sound use the emulator window. Editor, Git, terminal, recovery and optional source Agent use the shared workbench. Opening a project sends no AI request and launches no emulator.

BBC BASIC II reference

Source and dialect

Use increasing line numbers from 0 to 32767, full uppercase keywords and printable ASCII source. Variable names and strings retain their case. REM and DATA retain the remainder of the line as literal text; a star command at the beginning of a statement also remains literal. FN and PROC names are preserved. PTR, PAGE, TIME, LOMEM and HIMEM have distinct assignment and expression tokens. Branch references use BASIC II's encoded line-number form.

A tokenised line, including its four-byte header, is at most 255 bytes. The stored programme starts at &1900 and must remain below &3000. Build checks encoding, bounds and closed strings; the BBC interpreter checks full runtime syntax, expressions and memory use. Keyword abbreviations and newer BASIC dialect extensions are outside this source contract.

Structured programmes

10 PROCgreet("BBC")
20 PRINT FNdouble(21)
30 END
40 DEF PROCgreet(name$)
50 PRINT "HELLO ";name$
60 ENDPROC
70 DEF FNdouble(n)=n*2

Expected observation: HELLO BBC and 42. Define a procedure with DEF PROC and end it with ENDPROC. A DEF FN returns the expression after its equals sign. LOCAL limits variables inside procedures/functions. REPEAT and UNTIL form a loop; FOR, TO, STEP and NEXT control a counted loop. IF, THEN and ELSE choose a branch; ON ERROR can supply recovery code.

Native inline assembly

BBC BASIC's [ and ] assembler blocks execute inside the BBC interpreter when the BASIC programme runs. Set P% to your reserved code buffer and use a two-pass OPT loop as appropriate. Studio tokenises the surrounding BASIC expressions and preserves assembly mnemonics. This is separate from the ca65 assembly project and provides no Studio breakpoint or source-map integration.

BBC memory, graphics and sound

Plan the memory map

The Model B has 32 KB RAM. Studio's initial contract uses PAGE &1900 and a conservative &3000 programme ceiling, keeping source/code clear of the lowest native screen base. MODE 7 leaves more runtime space than the bitmap modes. Variables, arrays, the interpreter stack and inline machine code still consume memory: a successful build does not guarantee sufficient runtime workspace. Do not overwrite MOS or filing-system workspace.

Graphics and keyboard

MODE selects the display. COLOUR changes text colour; GCOL selects a graphics colour and action. CLG clears graphics; MOVE, DRAW and PLOT use graphics coordinates. VDU sends display-control values. MODE 7 uses character and teletext graphics rather than the bitmap pixel plotting of modes 0 to 6. GET waits for keyboard input, INKEY polls with a timeout, and their string forms return a character string.

Sound

SOUND takes channel, amplitude, pitch and duration. ENVELOPE defines changing pitch and amplitude. These calls target the BBC sound hardware through MOS. Test audible output in the real emulator; an encoded SOUND token and an opened audio device do not prove audible sound.

Files

The build disc contains only the programme and its boot script. CHAIN loads BASIC, while *RUN loads and executes a machine-code file using catalogue addresses. User changes inside a run affect only a disposable staged disc. Use Studio's guarded Export for a lasting build artefact. Arbitrary disc/tape import and direct physical-hardware transfer are not part of this increment.

BBC 6502 assembly

Build contract

Choose the 6502 assembly template and select ca65 V2.18 from cc65 2.19, with ld65 in the same directory. One .org $1900 begins the source. Use documented NMOS 6502 instructions, simple labels and .byte, .word and .res. The binary must remain below $3000. Includes, macros, imports, arbitrary linker configuration, 65C02 opcodes, bank switching and C are unsupported. The shared processor articles explain the instruction set and addressing modes.

Print a character through MOS

.org $1900
    lda #65
    jsr $FFEE
    jsr $FFE7
    rts

Expected observation: A followed by a newline and return to the BASIC prompt. OSWRCH at $FFEE outputs the character in A. OSNEWL at $FFE7 writes a newline. RTS returns to the filing system's caller. Prefer documented MOS entry points to private BASIC ROM routines.

Loading and execution

Studio places PROGRAM on a DFS disc with load and execution addresses $1900. Its !BOOT script selects MODE 7 and runs PROGRAM. This differs from the C64 SYS loader and PRG format. Editing an existing C64 project never changes its loader, origin or media format. There is no integrated BBC source debugger in this increment.

BBC tools and troubleshooting

Exact runtime and firmware

Select separately installed MAME 0.289 in Settings → Emulators → MAME executable for BBC Model B. Settings → Systems & Firmware → BBC Model B ROM folder must contain os12.rom (OS 1.2), basic2.rom (BASIC II) and dnfs120.rom (combined Acorn DFS 1.20/NFS 3.00), each 16,384 bytes. MAME also requires cm62024.bin (16,384-byte speech data, CRC-32 98e1bf9e), even with speech disabled, and saa5050 (960-byte character ROM, CRC-32 201490f3). Studio validates public revision fingerprints and compares framed SHA-256 identities while staging. Supply lawful originals; Studio neither downloads nor bundles them.

Separate family settings

C64 keeps its VICE executable and firmware folder. Source settings schema 3 adds a family-keyed emulator map; older C64 and Z80 settings remain readable. BBC never falls back to VICE. The same ca65/ld65 installation serves both 6502 machines.

Recover from a failure

If Build reports DBBC100, check line order, lengths, strings and the memory ceiling. DBBC102 indicates programme/disc packaging bounds. DBBC110 identifies a missing or wrong firmware revision. DBBC111 requires the supported MAME version. Save corrected source and rebuild. A version probe or live process is not evidence of successful BBC execution; inspect its window for errors and the expected programme output.

References and limits

BBC Model B with UK OS 1.2, BASIC II, DFS 1.20/NFS 3.00 and the 8271 controller is the only Acorn target. Master, Electron, other DFS/ADFS profiles, Tube processors, cassette workflows and IDE debugging are outside this increment. The browser edition supports BASIC projects, canonical SSD recovery and local Play under ADR 0055. Select the same five firmware files; they remain in volatile memory. Assembly requires the desktop tools.
