## BBC Model B project

This project targets the UK BBC Micro Model B with 32 KB RAM, OS 1.2,
BBC BASIC II, Acorn DFS 1.20/NFS 3.00 and the 8271 controller. Build produces a
deterministic 80-track, single-sided DFS `.ssd` containing `PROGRAM` and `!BOOT`.
Export creates a new file and never overwrites an existing destination.

BASIC uses full uppercase keywords and preserves the case of variables and
strings. Number lines in increasing order from 0 to 32767. Build validates
encoding and memory bounds; BASIC checks full syntax when run. Its native
inline assembler executes inside the BBC, rather than through Studio's ca65 path.

Assembly uses one `.org $1900`, documented NMOS 6502 instructions and simple
labels with `.byte`, `.word` and `.res`. Return with RTS. Studio starts in MODE 7;
code and BASIC programmes stay below $3000. Runtime variables and screen memory
still need planning. Includes, macros, C, multiple source files, bank switching,
tape workflows and IDE debugging are unavailable.

On desktop, configure separately installed MAME 0.289, ca65/ld65 V2.18 from cc65 2.19 for
assembly, and a lawful firmware folder containing `os12.rom`, `basic2.rom`,
`dnfs120.rom`, `cm62024.bin` and `saa5050`. No firmware or emulator is supplied. Run builds fresh output;
Stop and Restart control only Studio's owned emulator. Input and audio use the
emulator window. Opening this project never executes anything.

The browser edition opens this same BASIC project and builds/exports its SSD.
Choose the five firmware files above for local Play; firmware stays in volatile
memory and is excluded from project recovery and ZIPs. Stop discards the runtime.
Only canonical BASIC SSDs generated by Studio can be recovered. Assembly needs
the desktop edition and its separately installed tools.
