## Verification

1. Build the saved source and inspect the successful DFS SSD result.
2. Export to a new `.ssd` destination; verify a second export refuses overwrite.
3. With lawful matching firmware and separately installed MAME 0.289, Run and
   observe the greeting/count (BASIC) or `A` followed by a newline (assembly).
4. Check keyboard input, Stop, Restart and a second Run. Verify failed builds
   retain prior output but never launch it. Record platform and tool versions.

An automated build does not establish video, sound, input, accessibility,
physical BBC hardware or packaged-app acceptance.
